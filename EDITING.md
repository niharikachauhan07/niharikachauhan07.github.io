# Editing Niharika’s website

The site is made from a few files:

- `index.html` — headings, paragraphs, links, and page content.
- `styles.css` — colors, type, spacing, layout, and visual effects.
- `script.js` — the interactive timeline and animation behavior.
- `assets/` — the portrait and site icon.

Open the relevant file in a text or code editor, make the change, and save. To preview it, refresh `index.html` in your browser. To update the live GitHub Pages site, upload the changed site files and the `assets` folder to the same repository, then commit the changes.

For a small content edit, start in `index.html`. Keep its HTML tags and section IDs intact so the page navigation continues to work.
